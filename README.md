# Диффи — Хеллман и MITM-атака

Учебный проект: показать, как работает обмен ключами по протоколу Диффи — Хеллмана, и продемонстрировать, как атака «человек посередине» (MITM) его ломает, если нет аутентификации.

Стек: Python, стандартная библиотека (`socket`, `hashlib`).

---

## Как работает протокол Диффи — Хеллмана

Два участника хотят договориться об общем секрете через открытый канал, не передавая секрет напрямую.

Общие параметры (известны всем):
- `g = 2` — генератор
- `p = 23` — простое число

Каждый выбирает случайное **секретное** число и вычисляет из него **публичный** ключ:

```
Алиса: секрет a = 14,  публичный A = g^a mod p = 2^14 mod 23 = 8
Боб:   секрет b = 10,  публичный B = g^b mod p = 2^10 mod 23 = 12
```

Они обмениваются публичными ключами и независимо вычисляют **общий секрет**:

```
Алиса: B^a mod p = 12^14 mod 23 = 4
Боб:   A^b mod p =  8^10 mod 23 = 4  ← одинаково!
```

Магия в том, что `B^a = (g^b)^a = g^(ab) = (g^a)^b = A^b mod p`.  
Перехватчик видит только `A` и `B`, но вычислить `g^(ab)` из них без знания `a` или `b` — вычислительно сложно (задача дискретного логарифма).

Полученный секрет используется как ключ шифрования: берётся его `SHA-256` хэш, и сообщения шифруются через XOR с этим хэшем.

## Структура проекта

```
user.py      — классы User и Mellory с математикой DH и XOR-шифрованием
Alice.py     — клиент (подключается к серверу на порту 9000)
Bob.py       — сервер (слушает порт 9001)
Mellory.py   — MITM-атака (стоит между Алисой и Бобом)
```

### user.py

Класс `User`:
- `generate_public_key()` — вычисляет `g^secret mod p`
- `generate_secret_key(publicKey)` — вычисляет `publicKey^secret mod p` (общий секрет)
- `crypt_message(message, key)` — шифрует строку через XOR с SHA-256 от ключа
- `encrypt_message(message, key)` — расшифровывает (XOR симметричен, та же операция)

Класс `Mellory` — то же самое, но отдельный объект для атакующего.

### Alice.py

Алиса работает как клиент:
1. Генерирует публичный ключ `A`
2. Подключается к серверу (в нормальном сценарии — к Бобу, в MITM — к Мэллори)
3. Отправляет `A`, получает `B` (или ключ Мэллори)
4. Вычисляет общий секрет и начинает чат

### Bob.py

Боб работает как сервер:
1. Генерирует публичный ключ `B`
2. Принимает подключение
3. **Сразу отправляет `B`** первым (важно для порядка в MITM)
4. Получает `A` (или ключ Мэллори), вычисляет общий секрет и начинает чат

### Mellory.py

Мэллори стоит посередине: для Алисы притворяется Бобом, для Боба притворяется Алисой.

---

## Сценарий 1: нормальный чат (без атаки)

> Нужно изменить `PORT` в `Alice.py` на `9001`, чтобы Алиса подключалась напрямую к Бобу.

Запустить в двух терминалах:

```bash
# Терминал 1
python3 Bob.py

# Терминал 2
python3 Alice.py
```

Алиса и Боб выведут одинаковый `secret key = 4` и смогут переписываться — сообщения шифруются.

---

## Сценарий 2: MITM-атака

```bash
# Терминал 1 — запустить первым
python3 Bob.py

# Терминал 2 — запустить вторым
python3 Mellory.py

# Терминал 3 — запустить последним
python3 Alice.py
```

### Что происходит:

```
Алиса                  Мэллори                  Боб
  |                       |                       |
  |──── A (публичный) ───>|                       |
  |                       |──── M (свой ключ) ───>|
  |                       |<─── B (публичный) ────|
  |<─── M (свой ключ) ───|                       |
  |                       |                       |
  | (думает, что секрет с Бобом)   (думает, что секрет с Алисой)
  |                       |                       |
  |══ зашифровано ключом sA ══>|                  |
  |              [Мэллори читает открытый текст]  |
  |              |══ зашифровано ключом sB ══════>|
```

Мэллори вычисляет **два** общих секрета:
- `sA = A^m mod p` — с Алисой
- `sB = B^m mod p` — с Бобом

Каждое сообщение Мэллори расшифровывает одним ключом и перешифровывает другим. Алиса и Боб не подозревают о перехвате — чат работает как обычно. В терминале Мэллори видны все сообщения в открытом виде.
