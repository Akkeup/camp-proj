Задание: Демонстрация протокола Диффи — Хеллмана и MITM-атаки upt: using web Socket

Суть: Учебный проект: реализовать обмен ключами по протоколу Диффи — Хеллмана между двумя сторонами, а затем показать, как атака «человек посередине» способна его скомпрометировать без аутентификации.

Стэк: Python, модуль cryptography или собственная реализация модульной арифметики

Что реализовать: реализация протокола между «Алисой» и «Бобом» с общим секретным ключом; отдельный скрипт-демонстрация MITM без проверки подлинности сторон; описание в README, как аутентификация (подпись) закрывает эту атаку; наглядная схема обмена в самом отчёте.
